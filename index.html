CORE TRIAGE

SOC L1 Investigation Order

1. Validate the rule and timestamp → 2. identify source and target → 3. enrich IP, domain or hash → 4. inspect endpoint and identity telemetry → 5. correlate scope → 6. classify, document and escalate.

Authentication Attack

Count failures and targeted accounts → identify any success → review MFA and device → enrich source IP → disable/escalate if compromise is confirmed.

Endpoint Execution

Review parent-child process chain → command line and signer → file hash → network activity → affected hosts → isolate and escalate malicious execution.

Command & Control

Measure beacon interval → process owner → destination reputation → bytes transferred → peer endpoints → contain confirmed beaconing.

Privilege / Lateral Movement

Validate change authorization → inspect 4624/4672/4732 events → review remote service or WinRM → scope accounts and endpoints → escalate unauthorized access.

Phishing / Cloud Identity

Review sender and URL → click and payload events → credential submission → sign-ins and OAuth grants → revoke sessions, disable account and escalate when needed.
