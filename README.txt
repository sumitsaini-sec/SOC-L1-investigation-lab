SOC L1 Investigation Lab v3
===========================

Open index.html in a modern browser.

New in v3:
- 560 unique alerts across 16 SOC detection scenarios
- Different timestamps, counts, severity, complexity, risk and evidence per case
- IP/IOC enrichment, process, network, authentication, scope and raw logs
- Required investigation checklist and six-part decision scoring
- Detection rule and log-source health view
- Add Alert form
- Automatic browser persistence
- Reopen investigated alerts with saved decisions and notes
- Investigation History
- Export/Import Progress JSON
- GitHub-ready README.md, LICENSE and .gitignore

All data is synthetic and intended for defensive cybersecurity training.
